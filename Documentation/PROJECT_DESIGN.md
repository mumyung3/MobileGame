# Project Design Documentation

## 프로젝트 설계 문서

이 문서는 SuperCent 모바일 게임 프로젝트의 설계 다이어그램들을 설명합니다.

## 📋 설계 다이어그램 목록

### 1. 클래스 다이어그램 (Class Diagram)
**파일**: `클래스다이어그램.pdf`

게임의 주요 클래스 구조와 관계를 정의합니다:

#### 핵심 클래스 구조
- **GameManager**: 게임 전체 상태 관리
  - 게임 진행 상태
  - 점수 및 재화 시스템
  - 레벨 관리
  
- **PlayerController**: 플레이어 입력 및 상호작용
  - 터치 입력 처리
  - 플레이어 액션 관리
  
- **ObjectManager**: 게임 오브젝트 관리
  - Bucket (버킷)
  - Counter (카운터)
  - Oven (오븐)
  - MoneyFloor (돈 수집 구역)
  
- **UIManager**: UI 시스템 관리
  - HUD 표시
  - 메뉴 시스템
  - 업그레이드 UI
  
- **SaveManager**: 게임 데이터 저장/불러오기
  - PlayerPrefs 활용
  - 게임 진행상황 저장

### 2. 유스케이스 다이어그램 (Use Case Diagram)
**파일**: `유스케이스다이어그램.pdf`

플레이어와 시스템 간의 상호작용을 정의합니다:

#### 주요 유스케이스
1. **게임 시작**
   - 새 게임 시작
   - 저장된 게임 불러오기

2. **게임 플레이**
   - 자원 수집 (Collect Resources)
   - 아이템 생산 (Produce Items)
   - 돈 획득 (Earn Money)
   - 객체 상호작용 (Interact with Objects)

3. **업그레이드 시스템**
   - 장비 업그레이드
   - 생산 속도 증가
   - 수익 증대

4. **게임 관리**
   - 게임 저장
   - 설정 변경
   - 게임 일시정지

5. **수익화**
   - 광고 시청
   - 보상 획득

### 3. 시퀀스 다이어그램 (Sequence Diagram)
**파일**: `시퀀서다이어그램.pdf`

게임의 주요 프로세스 흐름을 시간 순서대로 표현합니다:

#### 주요 시퀀스 플로우

##### 게임 초기화 시퀀스
```
1. Unity 시작
2. GameManager 초기화
3. SaveManager로부터 데이터 로드
4. UI 초기화
5. 게임 오브젝트 생성
6. 게임 준비 완료
```

##### 자원 수집 시퀀스
```
1. 플레이어 터치 입력
2. PlayerController가 입력 감지
3. 해당 오브젝트와 상호작용
4. 자원 생성/수집
5. GameManager에 자원 업데이트
6. UI 업데이트
```

##### 업그레이드 구매 시퀀스
```
1. 업그레이드 버튼 클릭
2. UIManager가 업그레이드 UI 표시
3. 재화 확인
4. 구매 처리
5. 능력치 업데이트
6. UI 리프레시
7. 데이터 저장
```

##### 광고 시청 시퀀스
```
1. 광고 버튼 클릭
2. AdsManager 호출
3. Unity Ads 광고 로드
4. 광고 표시
5. 시청 완료 콜백
6. 보상 지급
7. UI 업데이트
```

## 🎮 게임 플로우 설계

### 핵심 게임 루프
1. **수집 (Collection)**: 기본 자원 수집
2. **생산 (Production)**: 수집한 자원으로 아이템 생산
3. **판매 (Selling)**: 생산한 아이템 판매로 돈 획득
4. **업그레이드 (Upgrade)**: 돈으로 시설 업그레이드
5. **확장 (Expansion)**: 새로운 기능 해금

### 진행 시스템
- **레벨 시스템**: 경험치 기반 레벨업
- **해금 시스템**: 레벨에 따른 새 기능 오픈
- **업적 시스템**: 특정 목표 달성시 보상

## 🏗️ 아키텍처 패턴

### 싱글톤 패턴 적용
- GameManager
- UIManager
- SaveManager
- AdsManager

### 오브젝트 풀링
- 자주 생성/삭제되는 오브젝트 재활용
- 돈 아이템, 파티클 효과 등

### 이벤트 시스템
- UnityEvents 활용
- UI와 게임 로직 분리
- 느슨한 결합 구조

## 📱 모바일 최적화 고려사항

### 성능 최적화
- 드로우 콜 최소화
- 텍스처 압축 활용
- LOD (Level of Detail) 적용

### 사용자 경험
- 직관적인 터치 컨트롤
- 빠른 반응성
- 부드러운 애니메이션

### 수익화 전략
- 보상형 광고
- 오프라인 수익
- 일일 보상 시스템

## 🔄 개발 우선순위

### Phase 1: 핵심 기능
1. 기본 게임 루프 구현
2. 터치 입력 시스템
3. 기본 UI 구성

### Phase 2: 게임 시스템
1. 자원 수집 메커니즘
2. 업그레이드 시스템
3. 저장/불러오기

### Phase 3: 확장 기능
1. 광고 통합
2. 업적 시스템
3. 일일 보상

### Phase 4: 폴리싱
1. 사운드 효과
2. 파티클 효과
3. 애니메이션 개선

## 📝 참고사항

- 모든 다이어그램은 게임 개발 진행에 따라 업데이트될 수 있습니다
- 실제 구현시 Unity의 컴포넌트 시스템을 최대한 활용합니다
- 모바일 플랫폼의 제약사항을 항상 고려하여 설계합니다
